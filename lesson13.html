第13回　自動化ツールを受け取る

12回かけて手でやってきた工程が、まとめて自動で流れます。この落差を体験するために、順番を作ってあります。

この回のゴール

自分専用の出版エージェントを持ち、自力で回せる状態。

ここがスクールの最終地点です。「本が1冊出せた」ではなく、 「本を出し続けられる状態になった」がゴールでした。

⚖ この資料の規約チェック
Amazon KDPの公式ヘルプを 2026-08-26 に読んで、この資料の内容と突き合わせています。

1. なぜ最後に渡すのか

ツールを最初に渡してはいけない理由が3つあります。
  1. 価値が伝わらない。苦労を知らない人にとって、自動化ツールはただのボタンです。 表紙のサイズで弾かれ、内容紹介の文字数で弾かれ、漫画のセリフを全部書き直した経験があって初めて、 「これが自動で終わるのか」という驚きになります
  2. 壊れたときに直せない。中で何をやっているか分からないまま使うと、 エラーが出た瞬間に手が止まります。手順を知っている人だけがツールを育てられます
  3. 判断が身につかない。ツールが出すのは選択肢であって、答えではありません。 テーマが良いか、表紙が競合に勝てるか、漫画が読まれるか。そこは人間が決めます
だからカリキュラムは「手でやる → 繰り返す → ツールを受け取る」の順に組んであります。

2. ツールが通す工程

工程対応する回
テーマのリサーチ第1回
目次の生成第2回
本文の生成第3回
挿絵の生成と配置第7回
漫画のネームと生成第8回・第9回
表紙の生成第4回
A+コンテンツ第10回
KDP登録情報のHTML化第6回
12回の内容が、そのまま1つずつ対応しています。 どの回で何をやったかを思い出せば、ツールのどこで何が起きているか分かります。

3. ツールの中で何が起きているか

ボタンを押すだけで使えますが、中身を知らないと育てられません。 最低限、次の3つの仕組みだけ覚えてください。

仕組み役割触るところ
設定ファイル読者・テーマ・キャラ・絵柄など、その本の前提1冊ごとに書き換える
ルールファイル「セリフに句読点を入れない」などの決まりここを自分用に書き換えて育てる
検査スクリプト出荷していい状態かを機械で判定する新しい失敗をしたら、検査を1行足す

4. 自分用に育てる

渡した時点のツールは、あくまで「型」です。 自分の絵柄・自分の口調・自分のジャンルに寄せていってください。
  • 絵柄を変える：キャラの設定と絵柄の指定を書き換える
  • 口調を変える：本文生成のルールに、自分の書き方の癖を足す
  • ジャンルを変える：リサーチの条件と、キーワードの決め方を書き換える
  • 失敗を足す：審査で落ちたら、まず検査スクリプトに1行足す。 ドキュメントに書くだけでは必ず忘れます
★失敗は資産です。 落ちた理由をメモして終わりにせず、「二度と同じことが起きない仕掛け」まで作ってください。 それが積み上がったツールは、他の誰も持っていないものになります。

5. 詰まったときの切り分け

症状まず見るところ
途中で止まった出力フォルダの更新日時。どこまで出来たかを確認して、残りだけ流す
変なものが出てくる設定ファイル。読者やキャラの指定が抜けていないか
ルールが守られていないルールファイル。生成前の検査が通っているか
エラーで動かないエラーの最後の3行をそのままAIに貼る。全部貼らなくていい
長時間のジョブが動いている間は、そのジョブが使うファイルを触らないでください。 途中でプロセスが落ちて、それまでの分がむだになります。直したいことはメモして、終わってからやる。

6. ここから先

12回かけて手でやってきた工程が、まとめて自動で流れます。
この落差を体験できるように、あえて順番を作ってあります。

ここから先は、あなたのペースです。月に1冊でも、3か月に1冊でも構いません。 大事なのは、止まらないことと、失敗をツールに書き足していくことです。

この回のプロンプト（コピーして貼るだけ）

ここまでのプロンプトを1本につないで、自動化します。

考えるのは「決めること」だけ。ひねり出す作業はAIにやらせます。
プロンプトは完成した状態で置いてあります。コピーして、【　】を自分のことに書き換えて、AIに貼る。それだけです。

使い方（ここだけは先に読んでください）
  1. プロンプトは全部こちらで用意してあります。ゼロから考えるところは1つもありません。「プロンプトをコピー」を押して、AIに貼るだけです。
  2. 直すのは【　】の中だけです。かっこごと消して、自分のことに書き換えてください。書き換えるのはたいてい1〜3か所です。
  3. プロンプトは上から順番に使ってください。前のプロンプトの答えを、次でそのまま貼って使います。
  4. この本のためのチャットを1つ作って、そこで続けてください。毎回新しいチャットにすると、AIが前の話を忘れて、また最初から説明することになります。
  5. 出てきた答えはそのまま採用しないでください。「そこは違う」と言い返すほど、あなたの本に近づきます。
  6. 無料のClaude・ChatGPT・Geminiで足ります。有料プランは要りません。
①自分のプロンプトを1本につなげる
★自動化の第一歩。ここまで使ってきたプロンプトを、1つの流れにまとめます。
これまでこの本を作るのに使ってきたプロンプトを、全部つなげて1本の手順書にしてください。

# 出し方
- 各ステップについて「入力（前のステップの何を渡すか）」と「出力（何が出てくるか）」を明記してください。
- ★受け渡すものが途中で切れていないかを確認して、切れていたら指摘してください。

# ルール
- 私が実際に使ってきたプロンプトの文面を、勝手に短くしないでください。
★これがあなた専用のツールの設計図になります。人によって順番も中身も違っていいものです。
②Claude Codeのスキルにする
★AICの受講生がいちばんつまずくところです。この手順書ごと貼ってください。
Claude Code で使う「スキル」を作りたいです。はじめてスキルを作る人に向けて、教えてください。

# やりたいこと
【①で作った手順書をここに貼る】
これを Claude Code に覚えさせて、1冊分をまとめて作れるようにしたいです。

# 教えてほしいこと（1つずつ順番に、画面のどこを押すかまで）
1. スキルを置くフォルダはどこか
2. スキルのファイルはどういう形式で、何を書くのか
3. 上の手順書を、スキルの形にどう書き換えるのか（実際に書いて見せてください）
4. 作ったスキルをどう呼び出すのか
5. うまく動かないときに、どこを見ればいいのか

# ルール
- ★パソコンが得意でない人向けに書いてください。専門用語は使わないでください。
- 各手順に「うまくいったかどうかの確認の仕方」を1行つけてください。
- いっぺんに全部やらせないでください。1つずつ、確認しながら進める形にしてください。
★AICのチャットでも「スキルの使い方が全然わからない」「自動化できるのはわかるが使い方が難しすぎる」という声が出ています。ここは1人で悩まず、このプロンプトでAIに1つずつ聞いてください。
③自分用に育てる
渡された型を、自分の絵柄・口調・ジャンルに寄せます。
# 前提
【いま使っているスキルの中身を貼る】

# やってほしいこと
このスキルを、私用に書き換えたいです。次のどれを変えたいか私が選ぶので、
それぞれについて「どのファイルの、どの行を、どう書き換えるか」を教えてください。

1. 絵柄を変える（キャラの見た目・線・色数）
2. 文章の口調を変える（私の書き方の癖に寄せる）
3. ジャンルを変える（リサーチの条件とキーワードの決め方）
4. 章の数や文字数を変える

# ルール
- 書き換える前と後を、必ず並べて示してください。
- ★1か所ずつにしてください。いっぺんに変えると、何が効いたか分からなくなります。
★渡した時点のツールはあくまで型です。自分の絵柄・口調・ジャンルに寄せていくほど、他の誰も持っていないものになります。
④失敗を検査に足す
★失敗は資産です。同じことを二度やらないための仕掛けを作ります。
出版で問題が起きました。同じことが二度と起きないようにしたいです。

# 起きたこと
【何が起きたか。審査に落ちた／絵が崩れた／文字が読めなかった など】
【言われた理由や、気づいたきっかけ】

# やってほしいこと
1. 原因を、思い込みでなく事実から特定してください。分からない部分は「不明」と書いてください。
2. ★これを「作る前に機械で見つける」にはどうすればいいかを提案してください。
3. その検査を、いま使っているスキルのどこに足すかを具体的に書いてください。
4. 検査がちゃんと動くか確かめるために、わざと壊したデータの例も作ってください。

# ルール
- ★「気をつける」で終わらせないでください。次も必ず忘れます。
- 文章のメモではなく、機械が判定できる形にしてください。
★ドキュメントに書くだけでは必ず忘れます。検査に1行足すところまでやって、はじめて「二度と起きない」になります。

7. 提出物

ツールを使って、3冊目のKDP登録情報まで自力で出力できたこと。
  • ツールを自分の環境で動かせた
  • 設定ファイルを3冊目の内容に書き換えた
  • ルールファイルを1か所でも自分用に書き換えた
  • 3冊目のKDP登録情報まで出力できた
  • 途中で詰まったところを記録した

7. 質問メモ欄

分からないことが出てきたら、まずAIに聞いてください。「＿＿＿が分かりません。はじめてやる人に向けて、手順を1つずつ教えてください」と打てば、たいていは解決します。
