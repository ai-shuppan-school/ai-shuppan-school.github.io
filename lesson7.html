LESSON 07

第7回　挿絵を入れる

挿絵は飾りではありません。読者に何を分からせるための絵か。それを決めてから作ります。

この回のゴール

文章の理解を助ける挿絵が、章ごとに配置されている状態。

ここからフェーズ2です。1冊目で出版の流れは掴んでいます。 ここからは「読まれる本」にする技術に入ります。

⚖ この資料の規約チェック
Amazon KDPの公式ヘルプを 2026-08-26 に読んで、この資料の内容と突き合わせています。

1. 挿絵は「図解」です

きれいな絵を入れても、読了率は上がりません。 上がるのは「文章だけでは分かりにくいところ」に絵が入ったときだけです。

作る前に、その絵1枚につき1行で書いてください。

この絵は、読者の「＿＿＿が分からない」を解消するために置く。

これが書けない絵は、入れなくていい絵です。

入れる価値がある挿絵入れても効かない挿絵
手順の流れ（①→②→③）章の扉に置いた、ただの風景
2つを見比べる図（before / after）本文をそのまま絵にしただけのもの
関係の図（誰と誰がどうつながるか）意味のないイメージカット
数字の変化（グラフ・目盛り）文章と関係のないキャラの立ち絵

2. 枚数と置き場所

  • 1章につき2〜4枚が目安。6章なら12〜24枚
  • 置くのはその説明の直後。章の頭にまとめて置かない
  • 同じページに2枚並べない（スマホでは片方が切れます）

3. 絵柄をそろえる（ここで素人っぽさが出ます）

絵柄がバラバラだと、中身が良くても一気に素人臭くなります。 1枚ずつ別々に作ると、必ずバラバラになります。
先に「絵柄の決め」を1つ作って、全部の絵で同じものを使う。
線の太さ・色数・塗り方・背景の有無・文字を入れるか。この5つを最初に決めて固定します。
決めること例
線細い黒線／太い線／線なし
色数3色まで（本文の読みやすさが変わります）
塗りフラット塗り／グラデーションなし
背景白のまま（本文の背景と同じ）
文字絵の中に日本語を入れるか。入れるなら全部の絵で入れる

4. キャラクターを出す場合

  • 外見を先に固定する。髪型・髪色・服・体型・年齢。曖昧だと途中で別人になります
  • 登場は2〜3人まで。多いと読者が覚えられません
  • 1冊を通して同じ立ち絵を使い回すのがいちばん崩れません

5. 拡大して確認する（絶対に飛ばさない）

縮小した一覧では、手指の破綻や左右の崩れを必ず見落とします。 サムネイルで並べて「よさそう」と判断しないでください。 1枚ずつ、原寸まで拡大して見てください。
  • 指の本数がおかしくない
  • 左右対称のもの（目・靴・袖）が崩れていない
  • 文字が入っている絵で、文字化けや意味不明な文字列がない
  • 人の体の向きと顔の向きが噛み合っている
  • 前の絵と同じキャラが、同じ人に見える

6. ファイル形式とサイズ

挿絵と漫画はPNGのままでよい（画質重視）。JPEG必須なのは表紙だけです。
  • 本文に入れるときの幅は28cmで統一。縦横比は保つ
  • キャプション（絵の下の説明文）は付けない。Kindleでは位置がずれます
  • 絵の中で説明したいことは、絵の中に描き込む

この回のプロンプト（コピーして貼るだけ）

挿絵は「何を分からせる絵か」を決めてからAIに作らせます。

考えるのは「決めること」だけ。ひねり出す作業はAIにやらせます。
プロンプトは完成した状態で置いてあります。コピーして、【　】を自分のことに書き換えて、AIに貼る。それだけです。

使い方（ここだけは先に読んでください）
  1. プロンプトは全部こちらで用意してあります。ゼロから考えるところは1つもありません。「プロンプトをコピー」を押して、AIに貼るだけです。
  2. 直すのは【　】の中だけです。かっこごと消して、自分のことに書き換えてください。書き換えるのはたいてい1〜3か所です。
  3. プロンプトは上から順番に使ってください。前のプロンプトの答えを、次でそのまま貼って使います。
  4. この本のためのチャットを1つ作って、そこで続けてください。毎回新しいチャットにすると、AIが前の話を忘れて、また最初から説明することになります。
  5. 出てきた答えはそのまま採用しないでください。「そこは違う」と言い返すほど、あなたの本に近づきます。
  6. 無料のClaude・ChatGPT・Geminiで足ります。有料プランは要りません。
①どこに挿絵が要るかを決めさせる
絵を作る前に「何を分からせる絵か」を決めます。
# 前提
【本文の原稿を貼る（章ごとでも構いません）】

# やってほしいこと
この原稿の中で、絵があったほうが分かりやすくなる場所を探してください。

# 出し方
表にしてください。列は次の4つです。
| 場所（章・節） | この絵は読者の「何が分からない」を解消するか | 絵の種類 | 絵の内容（1行） |

絵の種類は次から選んでください。
- 手順の流れ（①→②→③）
- 2つを見比べる図（before / after）
- 関係の図（誰と誰がどうつながるか）
- 数字の変化（グラフ・目盛り）

# ルール
- ★「何が分からないを解消するか」が書けない絵は、候補に入れないでください。
- 1章につき2〜4枚にしてください。多すぎると本文が読まれません。
- 章の扉に置くだけの風景画は提案しないでください。
★きれいな絵を入れても読了率は上がりません。上がるのは「文章だけでは分かりにくいところ」に絵が入ったときだけです。
②絵柄を先に固定させる
★これを先にやらないと、絵柄がバラバラになって一気に素人っぽくなります。
# 前提
本のテーマと読者：【第1回の設定シートを貼る】

# やってほしいこと
この本の挿絵の「絵柄の決め」を作ってください。全部の絵で使い回す共通設定です。

次の5つを決めて、そのまま画像生成AIに貼れる1つの文章にまとめてください。
1. 線（細い黒線／太い線／線なし）
2. 色数（★3色まで）
3. 塗り（フラット／グラデーションなし）
4. 背景（白のまま／薄い色）
5. 絵の中に日本語の文字を入れるか（入れるなら全部の絵で入れる）

# 出し方
- 決めた理由を1行ずつ。
- 最後に「絵柄の決め（コピー用）」として、生成AIに貼る文章を1つにまとめてください。
  ★この文章を、全部の絵の指示の先頭に貼って使います。
ここで出た「絵柄の決め」を保存しておいてください。これから作る絵の指示に毎回貼ります。
③1枚ずつ画像の指示文を作らせる
①の表と②の絵柄の決めを貼ってから使います。
# 前提
絵柄の決め：【②で出た文章を貼る】
作る絵：【①の表から1行を貼る】

# やってほしいこと
この絵を作るための、画像生成AIに貼る指示文を作ってください。

# 決まり
- 先頭に必ず「絵柄の決め」を丸ごと入れてください。
- 何を描くかを、位置関係まで具体的に書いてください（左に〜、中央に〜、右に〜）。
- ★絵の中に入れる日本語の文字がある場合は、その文字を「」でくくって正確に指定してください。
- 縦横比を指定してください。

# 出し方
- そのままコピーして貼れる状態で、1つの文章として出してください。
- 説明や前置きはつけないでください。
★日本語の文字はAIが崩します。文字を入れる絵は、文字なしで作ってあとからCanvaで乗せるほうが確実です。
④できた絵を点検させる
★縮小した一覧では見落とします。1枚ずつ拡大してから貼ってください。
この挿絵を点検してください。

# 見てほしいところ
1. 指の本数がおかしくないか
2. 左右対称のもの（目・靴・袖）が崩れていないか
3. 文字が入っている場合、意味不明な文字列になっていないか
4. 人の体の向きと顔の向きが噛み合っているか
5. 前に作った絵と同じキャラが、同じ人に見えるか
6. 本文のどこを分からせる絵か、絵だけ見て伝わるか

# 出し方
- 各項目を「問題なし／要修正」で判定してください。
- 要修正があれば、★いちばん目立つ1か所★だけを指摘してください。
- 直すための指示文の書き換え案も添えてください。
背景が少し雑なくらいは通してください。読者はそこを見ていません。直すべきは、文字が読めない・キャラが別人・指が目立って変、の3つだけです。

7. 提出物

挿絵一式（PNG）＋「この絵は何を分からせるためか」の一覧。
  • すべての絵に「何を分からせるための絵か」が1行で書いてある
  • 絵柄の決め（線・色数・塗り・背景・文字）を先に決めて、全部で守った
  • 1枚ずつ拡大して確認した
  • キャラを出したなら、外見の設定が固定されている
  • PNGで保存されている

8. 質問メモ欄

分からないことが出てきたら、まずAIに聞いてください。「＿＿＿が分かりません。はじめてやる人に向けて、手順を1つずつ教えてください」と打てば、たいていは解決します。
それでも解決しないこと・自分では判断がつかないことだけ、ここに書き留めておいてください。迷った場所こそが、いちばん大事な情報です。
